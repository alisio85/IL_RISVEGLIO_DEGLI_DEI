# DM SCREEN — REFERENCE VELOCE D&D 5.5 (2024)

## 1. CONDIZIONI

| Condizione | Effetto | Durata tipica |
|------------|---------|---------------|
| **Affascinato** | Non può attaccare chi lo ha affascinato, vantaggio CHA vs | 1 min (incantesimo) o variabile |
| **Afferrato** | Velocità 0, può attaccare chi lo afferra; liberarsi CD FOR | 1 round o finché trattenuto |
| **Assordato** | Fallisce automaticamente prove di Percezione basate su suono | Variabile (incantesimo/ambiente) |
| **Avvelenato** | Svantaggio a tiri per colpire e prove di caratteristica | Fino a cura o CD COS |
| **Cieco** | Fallisce prove visive, svantaggio ATT, vantaggio vs ATT | Variabile (incantesimo/ambiente) |
| **Affaticato** | Liv.1: svantaggio prove; 5: velocità 0; 6: morte | Rimuovibile con riposo/incantesimo |
| **Impossibilitato** | Nessuna azione o reazione | Variabile |
| **Invisibile** | Vantaggio ATT, svantaggio vs ATT, non bersagliabile | Variabile (incantesimo) |
| **Paralizzato** | Incapacitato, fallisce FOR/DES, critico automatico in mischia | Variabile |
| **Pietrificato** | Peso ×10, resistenza a tutti i danni, incapacitato | Variabile |
| **Prono** | Svantaggio ATT; mischia vs ha vantaggio; distanza vs svantaggio | Fino a rialzarsi (metà movimento) |
| **Spaventato** | Svantaggio prove e ATT finché vede la fonte | Variabile |
| **Stordito** | Incapacitato, può solo parlare | Variabile |
| **Svenuto** | Incapacitato, prono, morto se PF=0, morto se 3 TS falliti | Fino a stabilità o cura |
| **Trattenuto** | Velocità 0, svantaggio ATT e TS DES, vantaggio ATT vs | Finché trattenuto |
| **Incosciente** | Svenuto + non sveglialo; identico a Svenuto | Variabile |

## 2. AZIONI IN COMBATTIMENTO

| Azione | Effetto |
|--------|---------|
| **Attacco** | 1 attacco (arma o incantesimo) |
| **Lanciare Incantesimo** | Lancia un incantesimo con tempo di lancio 1 azione o bonus |
| **Scatto** | Raddoppia velocità |
| **Disimpegno** | Muoversi senza provocare Attacchi di Opportunità |
| **Schivata** | Svantaggio ATT contro di te, vantaggio DES tiri salvezza |
| **Aiuto** | Alleato ha vantaggio a 1 prova/attacco |
| **Nascondersi** | CD Percezione nemico (Furtività vs Percezione passiva) |
| **Preparare** | Innesco + azione (reazione) |
| **Usare Oggetto** | Interagire con oggetto o attivare oggetto magico |
| **Cercare** | Percezione o Investigazione |
| **Studiare** | Prova INT (Arcano, Natura, Religione, Storia, Indagare) per analizzare |
| **Influenzare** | Prova CAR (Persuasione, Inganno, Intimidire, Interpretazione) |
| **Interazione gratuita** | 1/turno (aprire porta, sguainare, bere pozione) |

### Azioni Bonus

| Fonte | Azione |
|-------|--------|
| Combattere con due armi | Attacco extra con arma leggera (no mod danno) |
| Incantamento rapido | Stregone: metamagia |
| Abilità di classe | Vedi scheda del PG |

### Reazioni

| Tipo | Quando |
|------|--------|
| Attacco di Opportunità | Nemico lascia portata |
| Incantesimo con reazione | Vedi incantesimo (es. Scudo, Controincantesimo) |
| Abilità di classe | Vedi scheda |
