# QUICK REFERENCE — GIOCATORE

## AZIONI IN COMBATTIMENTO

| Azione | Effetto |
|--------|---------|
| **Attacco** | 1 attacco (arma o incantesimo) |
| **Scatto** | Raddoppia velocità |
| **Disimpegno** | Muoversi senza Attacco di Opportunità |
| **Schivata** | Nemici hanno svantaggio contro di te; vantaggio DES |
| **Aiuto** | Alleato ha vantaggio a 1 tiro |
| **Nascondersi** | CD Percezione del nemico |
| **Preparare** | Scegli innesco + azione; si attiva come reazione |
| **Cercare** | Percezione o Investigazione |
| **Interazione gratuita** | 1/turno: aprire porta, sguainare, bere pozione |
| **Usare Oggetto** | Attivare oggetto magico |

### Azione Bonus
- Attacco extra con arma leggera (seconda arma, no mod. danno)
- Abilità di classe (es. Incantamento Rapido, Ira, Giuramento)

### Reazione (1/round)
- Attacco di Opportunità (nemico lascia portata)
- Incantesimi con tempo di lancio "reazione"
- Abilità di classe

## REGOLE CAMPAGNA — RIEPILOGO

### Frammento Interiore
- Ogni PG ha un frammento dormiente (liv. 1-4)
- Al liv. 5: si risveglia → poteri + resistenza necrotico
- 12 frammenti totali. Ognuno ha un colore e un tema.
- I frammenti vicini danno bonus di gruppo (sinergia)

### Viaggio Multiversale
- Attraverserete: Forgotten Realms → Spelljammer → Ravenloft → Strixhaven → Eberron → Dragonlance → Theros → Feywild → Sigil → Piani Esterni → Cuore del Multiverso
- Nave: **La Farfalla Stellare** (nave spelljammer potenziabile)
- Portali: richiedono chiavi, parole d'ordine, o incantesimi

### Fazioni Amiche
- Arpisti (FR), Compagnia della Luce (Krynn), Strixhaven, Akropolis (Theros), Alleanza di Sigil
- Guadagnate reputazione con missioni e scelte

### Fazioni Nemiche
- **Alba Nera**: culto che serve Oblivios, vuole distruggere il multiverso
- **Xanathar** (ATTO I), **Signore della Guerra** (Eberron), **Voidrax** (Githyanki)

### Riposo per Ambientazione
| Dove | Riposo Lungo |
|------|-------------|
| Locanda sicura | 8 ore |
| Accampamento | 8 ore (possibile incontro) |
| Dungeon | 8 ore (probabile incontro) |
| Ravenloft | 24 ore |
| Celestia | 4 ore |

## COSA FARE TRA LE SESSIONI

- **Downtime:** Studio, lavoro, crafting, ricerca (parla col DM)
- **Diario di bordo:** Scrivi il riassunto della sessione → Ispirazione bonus
- **Obiettivo segreto:** Lavora verso il tuo obiettivo personale
- **Upgrade nave:** Se avete fondi, potete potenziare La Farfalla Stellare
