## Percorso di Lettura Consigliato

### Per il DM Nuovo (passo passo)

> Se è la prima volta che apri questo vault, segui quest'ordine. Non serve leggere tutto: bastano questi 4 passi per iniziare.

1. **→ Panoramica della Campagna** — capisci di cosa parla la storia, chi sono i Tessitori, cosa sono i Frammenti
2. **→ Ambientazione** — Faerûn come punto di partenza, il Feywild, il Multiverso in gioco
3. **→ Regole Speciali** — Frammenti, viaggio planare, piety, battaglie su larga scala
4. **→ Guida ATTO I** — struttura dell'ATTO, dungeon, boss, PNG essenziali
5. **→ Sessione 01: Il Mistero di Pietra dell'Alba** — prepara e gioca la prima sessione

### Per il DM Esperto (accesso rapido)

| Cosa cerchi | Vai a |
|-------------|-------|
| Stat block e incontri | Bestiario ATTO I |
| Regole frammenti | Regole Frammenti |
| Mappa del multiverso | Mappa Multiverso |
| Tutte le sessioni | Indice Generale |
| DM screen pronto | DM Screen Reference |

### Per i Giocatori

Consegna ai tuoi giocatori **uno o tutti** questi file prima della Sessione Zero:

- **Guida del Giocatore** — il file principale per i player
- **Primer per Giocatori** — stampabile, contesto iniziale senza spoiler
- **Quick Reference Giocatore** — regole speciali in formato sintetico
- **Scheda Frammento** — handout per il frammento di ogni PG

## Quick-Start: Prima Sessione in 10 Minuti

Hai 10 minuti? Ecco cosa fare:

1. **Leggi** Guida ATTO I (2 min) — struttura e tono
2. **Apri** Sessione 01 (3 min) — scorri le scene, segna i PNG principali
3. **Stampa** Primer per Giocatori (1 min) — dallo ai player
4. **Prepara** stat block: Bestiario ATTO I (2 min) — segna le creature della sessione
5. **Gioca!** (2 min residui per respirare) — il resto lo leggi tra una sessione e l'altra

## Consigli per l'Uso

1. **Non leggere tutto**: apri solo la sezione che ti serve per la prossima sessione
2. **Usa i wikilink**: i file sono collegati tra loro. Segui i rimandi
3. **Prepara una sessione per volta**: la campagna è flessibile, i PG faranno scelte imprevedibili
4. **Prendi appunti**: usa un editor per annotare le sessioni giocate
5. **Personalizza**: cambia ciò che non ti piace. È la TUA campagna ora
