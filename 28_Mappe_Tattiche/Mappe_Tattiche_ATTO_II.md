## 1. LA CITTÀ DEI MORTI GITHYANKI (ATTO II, Cap. 1)

**Luogo:** Asteroide nello Spazio Selvaggio

### Layout
```
        ↑ Approdo (Farfalla Stellare)
   ┌──────────────────────┐
   │  [Colonne] [Colonne]  │  Piazza Centrale
   │          ◆           │  (statue githyanki)
   │  [Colonne] [Colonne]  │  ◆ = Puzzle piattaforme
   └──────────┬───────────┘
              ├────────────┐
   ┌──────────┴────────┐   │
   │  [Altare]    [Gemma]│   │  Tempio dei Defunti
   │          ◇         │   │  (campo di forza)
   └──────────┬─────────┘   │
              └─────────────┤
   ┌────────────────────────┘
   │  [Tesoro] [Voidrax]    │  Cripta del Drago
   │          ⌂            │  (Voidrax dorme)
   │  [Ossa]   [Ossa]      │
   └────────────────────────┘
```

**Descrizione:** "Una città di ossa e cristallo nero. Architettura gotica nello spazio. Figure si muovono tra le colonne. Il silenzio è assoluto — qui non c'è aria. Sentite le vostre voci vibrare nelle vostre teste."

**Ambiente:** Vacuum spaziale. I PG necessitano di respirazione magica o elmi spelljammer.

**Elementi tattici:**
- **Puzzle Piattaforme (◆):** 4 piattaforme. Ordine corretto: Sole→Luna→Stella→Cometa. Sbagliato: 2 statue animate (CR 5).
- **Altare:** contiene il frammento, protetto da campo di forza. Chiave: gemma nel cuore di Voidrax.
- **Voidrax:** drago spaziale CR 8. Non necessariamente ostile. Prova di valore per ottenere la gemma.

## 3. CASTELLO RAVENLOFT — SALA DA BALLO (ATTO II, Cap. 3)

**Luogo:** Castello Ravenloft, Barovia

### Layout
```
   ┌────────────────────────┐
   │  [Colonne]  [Colonne]  │  Colonne in pietra nera
   │                       │
   │    [Tavolo]            │  Tavolo del banchetto
   │        del             │  (copertura, armi? nascoste)
   │      Banchetto         │
   │                       │
   │  [Colonne]  [Colonne]  │
   └──────┬────────────────┘
          │
   ┌──────┴────────────────┐
   │  [Scale]   [Trono]    │  Trono di Strahd
   │            ⌂          │  ⌂ = Strahd (boss)
   │  [Scale]   [Organo]   │  Organo: l'organista fugge
   └───────────────────────┘
```

**Descrizione:** "Una sala immensa. Candele nere illuminano tavole imbandite. Un organo suona una melodia funebre. Sul trono, Strahd sorseggia un calice di vino rosso. 'Benvenuti. Vi aspettavo.'"

**Elementi tattici:**
- **Tavolo:** capovolgere per copertura (azione). Nascondere armi sotto.
- **Colonne:** copertura parziale (+2 CA). Scalabili (CD 12).
- **Organo:** 1d8 psichici/round se qualcuno suona una nota stonata. CD 16 Intrattenere per suonare una melodia che affascina Strahd 1 round.
- **Scale:** portano al piano superiore (fuga di Strahd se necessario).

**Atmosfera:** Gotica, opprimente. Strahd controlla la sala (può aprire/chiudere porte, spegnere luci).

```
   ↑ Ingresso (porta di ferro, CD 18 FOR)
   ┌────────────────────────┐
   │ [Macchinari]  [Ganci]  │  Piano 1: Fabbrica
   │            (warforged  │  (gas magitech)
   │ [Macchinari]   incompleti)│
   └────────────┬───────────┘
                 │ (scala)
   ┌────────────┴───────────┐
   │ [Laboratorio] [Documenti]│  Piano 2: Laboratorio
   │ [4 warforged ostili]   │  Documenti: "Progetto Anima"
   └────────────┬───────────┘
                 │ (scala)
   ┌────────────┴───────────┐
   │          ■              │  Piano 3: Cuore Forgiatura
   │       [Fornax]          │  ■ = gabbia di energia
   │       ⌂ (Malkor arriva) │  Fornax = warforged guardiano
   └────────────────────────┘
```

**Descrizione:** "Odore di olio bruciato e metallo. Warforged incompleti pendono da catene. Un ronzio di macchinari riempie l'aria. In profondità, una luce viola pulsa."

**Trappola:** Gas magitech (CD 15 COS o 2d6 veleno).

**Elementi tattici:**
- **Macchinari:** copertura (+2 CA). Possono essere sabotati (CD 14) per creare esplosione (3d6 fuoco, 10 ft).
- **Ganci:** salire al soffitto (CD 14 Atletica). Vantaggio contro nemici a terra.
- **Gabbia di energia:** distruggibile (80 PF) o disattivabile (CD 18 Arcano).
- **Malkor l'Ombra:** warlock CR 7. Attacca con 4 warforged dopo la scelta del frammento.

   │   ×              ×             ×       │  × = baliste
