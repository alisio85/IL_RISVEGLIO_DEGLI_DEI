# MAPPE TATTICHE — ATTO I (Liv. 1-5)

Descrizioni testuali delle arene di combattimento e luoghi chiave per il DM.

## 1. IL COVO DEL CULTO (ATTO I, Cap. 1)

**Luogo:** Sotterraneo sotto la cripta del tempio di Lathander, Pietra dell'Alba

### Layout
```
        ↑ Scala verso il tempio
   ┌──────────────────────┐
   │   [Porta]     [Rack]  │  Stanza 1: Deposito
   │                      │  (3 cultisti iniziali)
   └──────────┬───────────┘
              │ Corridoio
   ┌──────────┴───────────┐
   │ [Altare]    [Fuoco]   │  Stanza 2: Sala rituale
   │          ⌂           │  (Capocultista + 2 cultisti)
   │   [Cerchio runico]   │  ⌂ = Il Sussurrante (boss)
   └──────────┬───────────┘
              │
   ┌──────────┴───────────┐
   │   [Gabbie]   [Tavolo] │  Stanza 3: Prigione
   │                      │  (1 cultista, prigionieri)
   └──────────────────────┘
```

**Descrizione:** "Un corridoio di pietra umida. Torce fumose illuminano statue di divinità sconosciute. Un cerchio runico viola pulsa sul pavimento — l'energia di Oblivios."

**Dimensioni:** Ogni stanza 30×30 ft. Corridoi larghi 10 ft.

**Elementi tattici:**
- **Cerchio runico (Stanza 2):** chi lo calpesta subisce 1d4 necrotici/turno. Può essere disattivato con CD 15 Arcano.
- **Fuoco (Stanza 2):** dannoso se attraversato (1d6 fuoco). Può essere usato per spingere nemici.
- **Gabbie (Stanza 3):** prigionieri possono essere liberati (azione bonus). Diventano alleati (2 NPC, CR 1/4).
- **Rack (Stanza 1):** copertura parziale (bonus +2 CA).

**Illuminazione:** Fioca (10 ft di luce, 20 ft di penombra). Scurovisione utile.

## 2. LA FORGIA SEGRETA (ATTO I, Cap. 2)

**Luogo:** Sotterranei di Waterdeep, laboratorio di Xanathar

### Layout
```
        ↑ Ingresso (scala)
   ┌──────────────────────┐
   │  [Colonne] [Colonne]  │  Zona 1: Ingresso
   │                      │  (gargoyle appostati)
   │  [Colonne] [Colonne]  │
   └──────────┬───────────┘
              │
   ┌──────────┴───────────┐
   │ [Fucina] [Incudine]   │  Zona 2: Forgia
   │          ■            │  (Golem di carne + spia)
   │ [Mantici] [Mantici]   │  ■ = Xanathar (boss)
   └──────────┬───────────┘
              │
   ┌──────────┴───────────┐
   │  [Baule] [Scaffali]   │  Zona 3: Deposito
   │                      │  (trappola a dardi)
   └──────────────────────┘
```

**Descrizione:** "Il calore della forgia vi colpisce come un'onda. Una grande incudine al centro, mantici che pulsano come cuori di metallo. L'aria profuma di ferro fuso e sangue."

**Dimensioni:** Ogni zona 40×30 ft.

**Elementi tattici:**
- **Fucina (Zona 2):** danno da calore 1d6 fuoco se ci si passa sopra. Può essere usata per gettare nemici (2d10 fuoco).
- **Colonne (Zona 1):** copertura totale. I gargoyle attaccano dall'alto.
- **Mantici (Zona 2):** se distrutti, rilasciano vapore (nuvola 20 ft, CD 12 COS o accecato 1 round).
- **Baule (Zona 3):** trappola — CD 15 Percezione o 1d10×4 dardi.

**Altezza soffitto:** 15 ft (gargoyle possono arrampicarsi).

## 3. LA FORESTA DI CORMANTHOR (ATTO I, Cap. 3)

**Luogo:** Radura sacra nel cuore della foresta, dove dimora Verdanthar

### Layout
```
        ↑ Sentiero nord
   ┌──────────────────────┐
   │  🌳        🌳        │  Zona 1: Bosco spesso
   │      [Sentiero]      │  (imboscata goblin)
   │  🌳        🌳        │
   └──────────┬───────────┘
              │
   ┌──────────┴───────────┐
   │  🌳    ┌────┐  🌳    │  Zona 2: Radura
   │        │Lago│        │  (druido corrotto)
   │  🌳    └────┘  🌳    │  Lago: acqua bassa 3 ft
   └──────────┬───────────┘
              │
   ┌──────────┴───────────┐
   │  🌳   [Trono]   🌳   │  Zona 3: Trono del Drago
   │       di pietra      │  (Verdanthar, boss)
   │  🌳   [Rovine]  🌳   │
   └──────────────────────┘
        ↓ Sentiero sud
```

**Descrizione:** "Alberi secolari formano una cattedrale naturale. Al centro, un laghetto cristallino. Oltre, un trono di pietra antica dove riposa un drago verde."

**Dimensioni:** 80×100 ft totali. Ogni zona 30×30 ft.

**Elementi tattici:**
- **Alberi (🌳):** scalabili (CD 12 Atletica). Copertura parziale. Possono cadere (CD 15 FOR, area 10 ft, 2d6 danni).
- **Lago:** acqua bassa (terreno difficile). Se Verdanthar usa il soffio acido sull'acqua: nuvola di vapore 20 ft, 2d6 acido/round.
- **Trono di pietra:** offre copertura totale (+5 CA). Si arrampica (CD 14 Atletica).
- **Rovine:** terreno difficile. CD 14 Percezione per tesoro nascosto.

**Illuminazione:** Scarsa (foresta fitta). Verdanthar ha scurovisione.

## 4. LE ROVINE DI ILLEFARN (ATTO I, Cap. 4)

**Luogo:** Rovine naniche sotterranee, tempio del frammento

### Layout
```
        ↑ Ingresso (crollo)
   ┌──────────────────────┐
   │ [Statua] [Statua]     │  Sala 1: Vestibolo
   │          █           │  (puzzle delle statue)
   │ [Statua] [Statua]     │  █ = porta runica (chiusa)
   └──────────┬───────────┘
              │  (dopo puzzle)
   ┌──────────┴───────────┐
   │  [Mosaico]  [Fiamma]  │  Sala 2: Tempio
   │                      │  (2 costrutti + mistico)
   │  [Altare]    [Fiamma] │
   └──────────┬───────────┘
              │
   ┌──────────┴───────────┐
   │  [Sarcofago]  [Pozzo] │  Sala 3: Cripta
   │          ◇           │  (trappola gas + boss)
   │  [Scaffali] [Porta]   │  ◇ = Frammento del Primo Mattino
   └──────────────────────┘
        ↓ Porta segreta
```

**Descrizione:** "Rovine di un'antica civiltà nanica. Mosaici alle pareti raccontano storie di dèi e martelli. Nell'aria, polvere di secoli e l'eco di un potere dimenticato."

**Dimensioni:** Ogni sala 40×40 ft.

**Elementi tattici:**
- **Statue (Sala 1):** 4 statue di guerrieri nani. Si attivano se il puzzle è sbagliato (CR 3 ciascuna). Se i PG risolvono il puzzle (ordine corretto: Sole, Stella, Luna, Montagna), le statue non attaccano.
- **Fiamme (Sala 2):** fuochi eterni. Danno 2d6 fuoco se attraversati. Illuminano la sala.
- **Altare (Sala 2):** copertura parziale. Può essere rovesciato (CD 16 FOR) per creare barricata.
- **Sarcofago (Sala 3):** contiene un boss non-morto se aperto senza rispetto.
- **Pozzo (Sala 3):** 60 ft di profondità. Cadere = 6d6 contundenti. CD 15 Percezione per notare.

## 5. IL CARNEVALE DELLA FATA-LUNA (ATTO I, Cap. 5 — Feywild)

**Luogo:** Il Feywild, dominio di Prismeer

### Layout
```
   ┌─────── Tentacolo del Carnevale ──────┐
   │                                       │
   │  [Gioco 1] ←── [Palco] ──→ [Gioco 2] │
   │       ↓                 ↑            │
   │  [Tiro a segno]   [Gioco 3: labirinto]│
   │       ↓                 ↑            │
   │  [Banchetto] ←── [Trono] ──→ [Bosco] │
   │                                       │
   └───────────────────────────────────────┘
```

**Descrizione:** "Luci fatate danzano tra tende di seta viola. Musica di flauti invisibili. Creature del Feywild ridono e giocano. Una grande tenda al centro, decorata di stelle e lune."

**Dimensioni:** 100×100 ft totali.

**Elementi tattici:** (Incontri non-combattimento)
- **Giochi:** 3 prove di abilità (vedi Sessione 08). Non ci sono combattimenti qui — ma se i PG attaccano, tutte le fate diventano ostili.
- **Palco:** performance. CD 14 per intrattenere.
- **Trono della Regina del Carnevale:** la Regina osserva. Non combatte.

**Illuminazione:** Luce fioca per via delle lanterne fatate.

**Atmosfera:** Magica, festosa, ma con un sottotono di pericolo. Il Feywild non dimentica gli insulti.
